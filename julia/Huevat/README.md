# Huevat.jl

Scientific palettes for Makie.jl and Plots.jl, using the same colors and
gradients as Python Huevat. Core, Earth and Gem provide categorical colors;
sequential, diverging and cyclic gradients cover continuous data.

Install from the repository with `Pkg.develop(path="julia/Huevat")`.
Plotting libraries are optional. See the [Julia guide](../../docs/JULIA.md)
for installation, figures and supported operations.
